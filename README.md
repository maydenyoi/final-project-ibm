# TikTok AI Hook & Caption Generator

Web ringan untuk membantu Content Creator TikTok menghasilkan ide *Hook* viral dan *Caption* terstruktur dalam hitungan detik.
Dijamin video Anda akan trending dan hype🫪😱

Fitur Utama:
1. **Smart Generator:** Menghasilkan 3 variasi hook dan 1 caption lengkap dengan CTA & Hashtag.
2. **Tone of Voice:** Pilihan gaya bahasa yang disesuaikan (Casual & Trendy, Witty, Professional, dll).
3. **History Log:** Menyimpan otomatis 5 riwayat pencarian terakhir menggunakan `localStorage`.
4. **One-Click Copy:** Tombol salin interaktif untuk kemudahan *copy-paste* ke TikTok.
5. **Dark Mode UI:** Desain antarmuka modern yang terinspirasi dari warna khas TikTok.

Teknologi yang Digunakan:
1. HTML
2. CSS
3. Vanilla JavaScript

Cara menjalankan:
Aplikasi ini berjalan sepenuhnya di sisi klien (*client-side*). Tidak perlu instalasi database atau backend.
1. Clone repository ini.
2. Buka file `index.html` di browser web apa pun.
3. Atau kunjungi versi live-nya di: https://maydenyoi.github.io/final-project-ibm/
